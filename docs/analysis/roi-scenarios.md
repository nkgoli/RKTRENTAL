# Named ROI scenarios and comparison extension

## State and public API

The declared projection predecessor `9124111b201277d5039b2bdd485019c08ec900e4` and corrected navigation candidate `6025e4fb3b699017b54d032d31cd2b4d06b2a6e6` were verified as ancestors of the assigned checkout. Its initial tree was clean; no retained scenario implementation was present. Work stayed in the assigned paths.

`RoiWorkspace` owns `ScenarioDraft[]` beside the existing base assumption strings. `scenarioDrafts` installs saved scenario identities, names, overrides and explicit options. `applyScenarios` creates the existing payload's scenarios without changing its base, benchmarks or evidence. Blank override fields inherit the base. Nonempty invalid numeric text stays in draft state and becomes a schema error at validation. Explicit fixed-dollar zero values remain explicit; inherited or overridden fixed amounts retain engine precedence over percentages. Dates accept the ISO timestamp format used by the public payload. No example scenarios are installed automatically.

The new functioning Scenarios tab stays mounted alongside Summary and Charts. Scenario edits set the same dirty/stale flags and pass through the same draft/ready action, expected revision, conflict lock and request token. Successful save/reload reinstalls scenario drafts. Property changes remount the presentation; no previous property's scenarios are rendered while loading. Scenario error paths remain `scenarios.<index>.name` or `scenarios.<index>.overrides.<group>.<field>`; correction opens Scenarios and its containing disclosures before focusing the entered value. The navigation dialog retains its own focus until correction is chosen.

`RoiScenarios` uses only `calculatePayload` against `calculatedPayload`. It hides stale comparisons. It shows current explicit assumptions against the current base, cards for base/custom cases, annual/monthly operating cash flow, cash-on-cash, hold-period leveraged IRR and percentage-point IRR deltas, plus equity before sale and cash-flow charts with exact annual tables. The chart horizon is temporary, bounded to 1 through the shortest modeled case hold (maximum 50 years); it does not reforecast, change scenario holds or save a changed base. IRR remains each case's complete hold-period metric. Dollar formatting retains cents, ratios retain null/Unavailable, and rate differences use percentage points. Tables scroll within the panel at phone widths.

Existing explicit scenario calculation options are displayed exactly and retained; the user can deliberately return them to inherited base options. This panel does not create tax/discount option presets. Custom input overrides cover every exposed base purchase, financing, income, expense and growth/exit field. The 20-case UI bound and public identity/field validation remain authoritative.
