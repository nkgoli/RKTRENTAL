## Design and component contract

Read coverage and system handoffs, shared-controls/responsive-navigation r7, dashboard-reference r5, and mind map r4 f-portals/c-ux. The diagram nodes have no additional file pointers.

The shared stylesheet is `src/styles/globals.css`, imported by the existing root layout. Its semantic tokens now use cobalt #3159d9, canvas #f7f9fc, white surfaces, text #17243b, muted #58687e, teal #087c91 and danger #b4233e. Success/warning/danger tints, strong input boundaries and cobalt focus remain text-labelled. Locally bundled variable Inter and Space Grotesk Latin fonts include their SIL licenses; other scripts use system fallbacks. Existing feature-specific legacy colors remain for their owners to reconcile.

- Existing Button variants, props and link/button semantics remain compatible. Controls use compact 36px desktop minimums and 44px phone/coarse-pointer targets; disabled text retains contrast. Primary pressed state removes its bottom shadow.
- Existing Field/Input/Select/Textarea/FormRow APIs remain compatible. Columns and controls can shrink within dialogs; phone rows stack, inputs use 16px text, readonly/disabled/invalid states are distinct. File inputs retain their uploader's sizing and hiding semantics. Consumers still own labels, validation messages and aria-describedby associations.
- Alert adds `tone="error"`, rendered with role alert; info/warning/success retain role status. This does not change feature error handling.
- New exported `TableRegion({ label, children })` is an opt-in named, focusable horizontal-scroll region. Wrap an existing Table and retain its caption, headers, financial columns and numeric alignment. Existing Table output is unchanged.
- Existing native dialog implementations retain focus containment, Escape, background inertness and restoration. Shared fields/buttons inherit the foundation; no modal state machine was replaced.
- Shell Icon keeps its existing name API, adds brand and distinct roi-analysis/rent-analysis names, and retains rent-comps as a compatible alias. Exact SVG primitives from light-system-icons.json are preserved, decorative and nonfocusable. Manager and tenant shell monograms share the approved geometry.
- ManagerShell keeps all routes and groups, active aria-current, hidden contextual rent comps, the separate Payments / ROI Analysis / Rent Analysis / Returns destinations and all drawer handlers. White 208px docked sidebar begins at 1024px; the drawer scrolls independently below it.
- TenantShell keeps Home / Pay / Lease / Repairs, role boundaries, 640px portal maximum, sticky header, fixed safe-area bottom navigation and 100px content reservation. Approved icons supplement visible link names.
