## Definitions and provenance

Bundled historical reference periods, return/yield/volatility values and source claims come from the imported RealROI metadata. These are explicitly unrefreshed assumptions, not verified quotations, live prices or actual historical series. Saved custom metadata overrides are preserved. CAGR includes reinvested distributions: yield is displayed but never added again. Cash-flow matching stays disabled.

Comparison starts with the property's total cash required and uses its modeled hold. Property interim series is year-end equity plus accumulated cash; its final point is net liquidation proceeds plus cash, deducting sale costs and debt payoff. Property cash is held without reinvestment. Public comparison return fields use percentage units; UI converts those to the fraction-based rate formatter and subtracts percentage units for percentage-point deltas. Annualized wealth growth is distinct from timing-aware leveraged IRR. Negative final property wealth retains its negative dollars and null annualized growth. Ranking uses final dollars; equal values receive equal displayed ranks. Zero capital has no index or comparison. Unsafe monetary precision produces an explicit error and no invented results.

The risk view shows source return/volatility references only. Property risk context uses model DSCR, worst annual cash flow, negative years and cash-only payback. Property volatility remains unmeasured; risk-adjusted comparisons remain unavailable. A negative cash-flow count is never called volatility or converted to a risk score.
