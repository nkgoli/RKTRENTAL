## Financial and state semantics

- Collected is payments received in the selected month. Outstanding includes charges due to date for the selected leases. Late is this month's rent past grace, with existing autopay/pending coverage rules and posted late fees. A property charge ledger can therefore show a past-grace charge while the rent roll identifies that lease as autopay. The UI explains the distinction without changing those rules.
- Return rates retain the selected-period calculations; they are not relabelled as annualized. Exact chart tables retain cents and negative NOI. Empty periods explain that there is no recorded income or expense instead of displaying an unexplained blank chart.
- The integrations service records setup activity as well as provider events. The new neutral “Activity recorded” state makes this limitation explicit; it does not claim that credentials or live availability have been verified. Sandbox activity is excluded from live activity counts.
- No processor, credential, permission, ledger allocation, fee, refund, payout or expense persistence implementation was changed. Existing confirmation behavior remains.
- Browser mutation checks use validation/non-submitting interaction. Financial mutations were exercised in mocked tests and the existing database tests' isolated organizations and sandbox adapters.
