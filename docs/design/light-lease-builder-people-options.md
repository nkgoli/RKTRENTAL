## Entry, saving and transitions

| Context/action                     | Existing behavior                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Applicant or existing tenant entry | The entry page matches applicant email case-insensitively, then falls back to `?tenant=` for preselection. An unmatched applicant gets the existing **isn’t a tenant yet. Add them as a tenant, then return here to select them.** message. Do not skip Tenants or add a conversion action.                                                                                                                                                  |
| Fresh renewal                      | [renewalDefaults](../../src/lib/lease-create/service.ts) carries tenant IDs and the prior primary, falling back to the first tenant. Preserve **Renew lease**, the header's **Renewal** label and **Renewal for … Tenants carry over from the current lease.** Selection remains editable.                                                                                                                                                   |
| Renewal Options defaults           | The entry page uses signed context/carried terms for `pets-allowed`, parking and utilities; balcony, laundry and flood fall back to unit/property values. Fresh renewal notice defaults to 60 and occupants to empty. Do not claim every option carries over. A resumed draft instead restores its saved values.                                                                                                                             |
| Saved draft                        | `loadLeaseDraft`, `coerceDraft` and the entry page restore fields, `step`, `furthestStep` and renewal identity. Returning to a unit/renewal with an open draft resumes it through `/leases/new?draft=…`. No autosave timer or new resume dialog.                                                                                                                                                                                             |
| Next                               | `next()` validates locally, then saves strictly; advance only after success. Tenants index 2 → Options index 3 → Clauses index 4 (`TemplateTermsStep`, `section="CLAUSE"`).                                                                                                                                                                                                                                                                  |
| Back / visited steps               | `jump()` saves non-strictly when a lease ID exists; otherwise it changes local step. Tenants Back → Rent index 1; Options Back → Tenants index 2. Only non-current steps at or before `furthestStep` are available. A check marker records navigation progress, not permanent validity.                                                                                                                                                      |
| Save and exit                      | `saveAndExit()` saves non-strictly, then navigates to `/leases?tab=drafts` only on success. Header back remains the separate direct property-leases link and does not invoke this action.                                                                                                                                                                                                                                                    |
| Pending / failure                  | `pending` disables fields, visited-step buttons, Back, Next and Save and exit, with **Saving…** status. Failure retains values and current step; service errors keep their returned message, while a thrown save uses **Your changes could not be saved. They are still here; try again.** Editing clears errors/message. Failure specimens have prior edits, hence **Unsaved changes**; the source's `dirty` state still governs the badge. |

All views remain inside `/leases/new`. Preserve the exact ten-step order from `WIZARD_STEPS`: Lease term → Rent, deposit & fees → Tenants → Options → Clauses → Rules → Disclosures → Attachments → Lessor info → Review & send. The main specimens set `furthestStep` to the current step; no later step is available or marked complete. Prototype links connect only matching Tenants/Options devices. Rent and Clauses destinations use action/step metadata rather than false links to another design family; implementation retains the existing handlers.

## Presentation and keyboard intent

Keep the reviewed Inter/Space Grotesk typography; cobalt `#3159d9`, teal `#087c91`, canvas `#f7f9fc`, white surfaces, text `#17243b`, muted `#58687e` and danger `#b4233e`. The original `.lw-*` stylesheet, 12px corners, 8px rhythm, 208px desktop step column and 1152px wrapper are retained. New choice styles reuse those variables. Tenants and document glyphs use the approved [icon primitives](light-system-icons.json); Back, Next and visited checks reuse the opening wizard.

At 390px, panels have 18px inner padding and 16px outer gutters. Options stack; utilities use two short columns. Native text/select controls are 16px with 44px minimum height, and checkbox labels provide large targets. Footer actions stay in normal flow below every field. Only the ten-step strip scrolls horizontally; retain the source's `scrollIntoView` for the current step, which static markup does not execute.

Preserve persistent labels, named groups, native checkbox/select keyboard behavior, associated hints/errors, `aria-invalid`, visible status text, disabled-fieldset semantics and the 3px focus outline. Retain heading focus on step change, error-summary focus on failure, and [useBuilderShell](../../src/components/lease-builder/useBuilderShell.ts) inertness/scroll restoration. The reference gallery is not a second state machine and must not be copied into product UI.
